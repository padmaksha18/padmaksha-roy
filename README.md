# Padmaksha Roy

Academic website for Padmaksha Roy, with a research profile, job-market contact, publication summaries, and original static scientific symbols.

Website: https://padmaksha18.github.io/padmaksha-roy/

This is a buildless static site. The main page is index.html; presentation and topic filtering are in site.css and site.js. The supplied CV is padmaksha-roy-cv.pdf. Publication versions share an entry where appropriate. Research links lead to primary publication records, open preprints, and author-provided code.

GitHub Pages publishes the main branch from the repository root.
